# Pet Code

 ##### Site de serviços para pet 


## Objetivos do projeto

> O Projeto foi desenvolvido por três pessoas, sendo elas, Evelyn (fez parte do Backend em php), Ana julia (fez o Frontend) e Giovanni (fez a montagem do banco de dados). A pet code tinha como objetivo facilitar na hora de encontrar algum serviço para seu animal de estimação.

### Status 
##### O status do projeto se encontra inativo

### Dificuldades
##### Durante o processo de desenvolvimento do projeto, eu, Evelyn fiz algumas observações sobre áreas de dificuldades durante o desenvolvimento, que me fizeram desistir do processo de aprimoramento do projeto
>- comunicação
>>Projeto me fez notar como a comunicação é crucial para um desenvolvimento eficaz, a falta de comunicação entre frontend e backend, fez com que cometessemos algumas incongruencias, descontentamentos e interpretações muito diferentes para se fazer a mesma ideia.
>- Inteligencia artificial
>> O uso excessivo de inteligência artifical em algumas partes do projeto também prejudicaram não só o projeto, como também nosso aprendizado.
